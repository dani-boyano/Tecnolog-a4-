## Presentación del proyecto
Este consiste en la creación de un sistema cíclico interconectado del empleo de agua en una ciudad simulada, en el cual se muestran fuentes que se intercomunican e interactuan con el usuario evitando al máximo el desperdicio de agua, dicha agua contaminada se dirigiría a un depósito, el cual dispensa agua en el caso de que la tierra de jardines y huertos públicos lo necesite.
